## 🔬 Featured Projects

### 1. MRI-Based Radiomics Analysis of Brain Tumors

**M.Sc. Dissertation | Central University of Punjab**

Comparative radiomic analysis of primary brain tumors and brain metastases using MRI data.

**Key Work:**
- MRI preprocessing and segmentation mask standardization.
- Radiomic feature extraction using PyRadiomics.
- First-order, shape and texture feature analysis.
- Statistical analysis using Shapiro-Wilk testing and Welch's t-test.
- Dimensionality reduction using PCA and UMAP.
- Machine learning classification using Random Forest.

**Technologies:** Python, PyRadiomics, SimpleITK, Pandas, Scikit-learn.
